Example custom Apache Solr 9.x collection, compatible with Solr Cloud.

Included Python indexing script for core (pyindexer.py). For use with Drupal Search API. Requires installation of pysolr package.

Setup DDEV Solr service:

ddev get ddev/ddev-solr

add example core (23100274-en) to .ddev/solr/configsets to create a SolrCloud collection
